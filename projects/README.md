# Работы: блок для главной и страница /portfolio

Оба блока строятся из одного списка `PROJECTS` в начале скрипта.

- `tilda-block.html` — блок на один экран для главной (T123).
- `tilda-page.html` — полная страница «Работы» (T123).
- `<slug>.mp4` — запись первого экрана сайта клиента, 800×500, до 9 с; `<slug>.jpg` — кадр из неё.
