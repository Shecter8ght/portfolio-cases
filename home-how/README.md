# Экран главной «Как я работаю»

`tilda-block.html` — код для блока T123 на главной ovchinnikov-dsgn.ru, заменяет старый блок «4 шага».
Слева четыре шага (разговор, структура и тексты, дизайн, запуск), справа закреплённое окно браузера: при прокрутке из разговора с владельцем собирается первый экран setka-garmoshka76.ru.

Новых медиа нет: берётся `setka-garmoshka/fold_home.jpg` через jsDelivr.
