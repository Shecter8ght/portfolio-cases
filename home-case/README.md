# Второй экран главной «Ваш случай»

`tilda-block.html` — код для блока T123 на главной ovchinnikov-dsgn.ru, ставится сразу под первым экраном.
Посетитель выбирает свой случай (сайта нет, заявок мало, сайт устарел, вырос из одностраничника) и видит живой сайт клиента и цифры из кейса.

Новых медиа нет: блок берёт видео и скриншоты из папок кейсов `cafe-prospect/`, `setka-garmoshka/`, `dentroom/`, `mirmo/` через jsDelivr.
Случаи, тексты и ссылки задаются массивом `CASES` в начале скрипта.
